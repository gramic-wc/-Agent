## 调参时最值得试的 5 个旋钮

1. `chunk split_text max_len`（700 → 400/1000）：颗粒度对召回影响最大
2. `RERANK_K`（30 → 15/50）与 `top_k`
3. 图纸描述 prompt（是否保留部件编号）
4. `MIN_CONFIDENCE`（0.35）：调高 → 转人工变多、错判变少
5. `MAX_TRIES`（1 → 2）：自检重判次数与延迟的权衡

## 已知失败模式（填进这里，别只在脑子里记）

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 型号不明的描述召回乱 | 未做设备型号过滤 | retrieve 前先 identify |
| 图表类问题答不出 | 图纸未做 VLM 描述 / 图注未关联 | 检查 `figure_no` 与 caption 距离阈值 |
| 引用指向不相关页 | rerank 关掉了或 chunk 太长 | 打开 rerank、缩短 chunk |
| 每次结论都不一样 | temperature 与 prompt 不稳定 | diagnose/plan 用 0.1~0.2 |
| **GA55 中文文本主力只有 20 页团标** | `GA55_instruction_book_en` 文字层坏，已降为只收图 | Day 6 补一份 GA55 中文操作/维修手册 |
| **不加型号过滤时跨设备污染 10%（多设备类 50%）** | 三台设备的“温度高/异响/振动”语义空间重叠 | Day 9 在检索层前加 device_model 过滤；但根子是“型号识别” |
| **d04/d06 故意不写型号时，top2/3 直接跑到 VMC850** | 没有型号 → 无法过滤 → 向量乱拉 | Day 8 的 identify 节点必须回答“认不出怎么办” |
| **无型号 query 靠内容“运气对”**（如“轴承温度高”返回全 YE3） | 只是向量恰好更近，换措辞就会变 | 不要依赖这种“看起来对”，Day 9 加过滤 |
| **正文块中位数 108 字、超短块 31.6%** | 切块偏碎 + 页眉页脚被当正文 | Day 3 调 `max_len`；Day 13 按“同文档重复短行”批量删页眉页脚 |
| 超短块里 284/440 来自 SINUMERIK 的页眉 | 页眉每页重复出现 | Day 13 用“重复度 ≥5 次的短行”规则清理 |
| **透视镜里文字和页码对不上：同页同类型的预览文字属于隔壁块** | **G 类：Qdrant 向量库与 `chunks.jsonl` 不是同一代**（`parse.py` 21:29 改过 → 21:32 重切了块，但 20:24 建的向量库没重建）；**2022 点里 494 个（24.4%）的 `chunk_id` 已不在新 jsonl（孤儿点）**；1528 个可对齐 id 里 629 个（41.2%）`payload.text` ≠ 同 `chunk_id` 的 jsonl 文本，其中 **563 真错位**（487 个严格 = 上一块）、**66 个只是旧解析的标点/空白差异** | 改完 parse/切块必须重建：`recreate_collection` + `uv run eq-ingest --no-vlm`；入库后自检 **点数 == `chunks.jsonl` 行数**（本次 2022 vs 2023，差 1） |
| **① dense 请求 30 条只返回 20 条** | 上一条的外显症状：孤儿点（494 个）占了 dense 名额，`_match_id()` 找不到就丢掉 → 真正的候选只有 20 条 | 以后看到“dense 条数不足 DENSE_K”先查点数一致性；孤儿点清掉后应回到 30 |
| **「表 20 振动强度限值」答不出来（示范 1）** | **H 类：top_k 名额截断**（原判 E 错）—— ② #3 / ③ #7 / ④ **#7**，重排根本没掉位；`hybrid.py` 里 `rerank(top_n=min(top_k,…))` 且 `top_k=6` → 第 7 名被截掉 | `top_k` 6 → 10 重测；**不要**先调 `RERANK_K`（③ 已第 7，调候选池救不了）；判 E 前必须看完整 30 条 |
| **d06 里真正应该回答的 `p14 table 1440`（含“检查加卸载动作”）四站全未进榜** | 上面那条的下游症状：dense 向量对的是隔壁块的文字；rerank 喂进去的也是错位文本，分数全部挤在 0.15x–0.17x | 先修 G，再看这条还在不在；**修库前不要调 RERANK_K / embedding / 切块** |
