# 手册放这里

把 15~25 份设备手册 PDF 放进本目录（可建子目录），然后跑 `uv run eq-ingest`。

## 采集建议（学习项目，别踩版权坑）

优先用**厂商官网公开发布**的手册/样本，只本地使用、不入库到 git：

| 设备 | 关键词 | 建议数量 |
| --- | --- | --- |
| 螺杆空压机（GA55） | `GA55 使用说明书 pdf`、`螺杆空压机 维护保养手册` | 6~8 |
| 立式加工中心（VMC850） | `VMC850 操作说明书 pdf`、`加工中心 维修手册` | 6~8 |
| 三相异步电机（YE3） | `YE3 系列三相异步电动机 样本`、`电动机 检修规程` | 5~8 |

挑文档的三条硬标准：

1. **要有表格**（参数表、故障码表、扭矩表）——否则表格链路测不出来
2. **至少 3 份含插图**（剖面图/流程图/接线图）——多模态才有意义
3. **要有目录和章节编号**——section_path 才有内容

## 自造兜底（拿不到手册时）

周三还凑不齐 15 份，就用 Word/PDF 自己写 10 篇结构化检修 SOP，每篇含：
故障现象表 + 可能原因表 + 步骤清单 + 一张示意图。质量差一点，但链路照样能跑通。

## manifest 格式（可选，用于精确指定型号）

不写 manifest 时按文件名关键词自动识别型号；文件名里没有信息就写一个：

```csv
file,doc_id,device_model,device_type,title
ga55/manual.pdf,ga55_manual,GA55,螺杆空压机,GA55 螺杆空压机使用说明书
```
