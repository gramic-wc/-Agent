# 第一部分 · 2.5 到底在干什么（12 分钟，只讲不动手）

## 1.1 一句话版本

> **命中率回答"有没有捞到"；2.5 回答"捞到的是不是那一条、如果不是，是 4 个环节里哪一个把它弄丢的"。**

把检索想成 **4 道筛子 + 1 条流水线**：

```
你的问题
  │
  ├─① dense  （向量，靠"意思像"）     取 30 张
  ├─② sparse （BM25，靠"字一样"）     取 30 张
  ├─③ RRF    （两榜合并，只看名次）    留 30 张
  └─④ rerank （逐条打分重排）          给 5~6 张
                                        ↓
                              你看到的 top5
```

**"正确答案那个块"（我们叫它「正确页」）就像一个包裹**，它有可能在任意一站被弄丢。
2.5 做的事，就是**查快递**：在第 ① ② ③ ④ 站的名单里分别找它一次，记下它排第几。

- ① 就没有 → 向量没找到它
- ② 里第 3、④ 里没了 → **重排把它压下去了**（最常见、也最容易冤枉向量模型）
- 四站都没有 → 可能**库里根本没有**（grep 证明）
- 有，但 `device_model` 是别人家的 → **跨设备污染**

> 💡 **一句话记住**：**正确页死在哪一站，就是哪一类问题。** 不用猜，去数名次就行。

## 1.2 三条判之前必须接受的规矩

| 规矩 | 为什么 | 具体怎么做 |
| --- | --- | --- |
| **坐标要 3 个字段：文档 + 页码 + 块类型** | 同一页经常被切成两块：`p21 text`（讲绝缘电阻）和 `p21 table`（表20 振动限值）是**两个东西**，混了必然判错 | 一律写成 `YE3-160M p21 table` 这种格式 |

### 🚨 本次判决：A–F 全不成立，新增第 7 类 **G（索引与切块不同步）**

**判 A 的理由不成立**：`chunks.jsonl` 里 grep 得到 685 / 1440 / 692 三块，库里不缺数据。
**判 C/D 也不成立**：1440 那块确实是超长表格块（37 行 1440 字）—— 但它连 ①② 都没进，
不是“进来后被长块挤掉”，不能算 D。
**判 E 只能骗自己**：692 那块确实 ③#2 → ④#5（掉 3 位），单看这条很像 E。**但 ④ 拿到的 `text` 不是它自己的**（见下）。

**真正的根因（脚本实测，非推测）**：

| 检查项 | 实测 |
| --- | --- |
| Qdrant 里 `payload.text` 是否等于 `chunks.jsonl` 同 `chunk_id` 的 text | **不等：1528 个 id 里 629 个不等（41.2%）** |
| 差的文本是谁的 | **487 个 = 上一个块（`jsonl[i-1]`）的文本**，整页位移一位 |
| 向量库文件的建库时间 | `data/qdrant/.../storage.sqlite` = **20:24–20:26** |
| `chunks.jsonl` 的重切时间 | **21:32**（`parse.py` 21:29 刚改过） |
| 点数一致性 | Qdrant **2022** 点 vs jsonl **2023** 行（差 1） |

→ 结论：**`parse.py` 改完只重跑了切块（chunks.jsonl），没重建向量库**。
旧库存的是上一版分块：旧版**不带页眉/标准号行**（`T/JSJXXHXX—XXXX` 这种），新版带 →
同页每个 `chunk_id` 里的文本整体后移一位。于是：

- ② BM25 走 `chunks.jsonl`（新）→ 正确文本，692 排第 2 ✅
- ① dense 走向量库（旧）→ 向量对的是隔壁块的文字 → **真正该答的 1440 表格块 ① 里 0 命中**
- ③ 融合把两代的 hit 混在一起 → **`chunk_id` 对、显示的文字错位**（我第一遍就被它骗了）
- ④ rerank 喂进去的是 `payload.text`（错位文本）→ 分数全挤在 **0.15x–0.17x** 一条线上，正确答案救不回来

**为什么这比 C/D/E 严重**：C/D/E 是“切块/重排策略不好”，还能调；这条是**索引和切块不是同一代**，
不修它，后面任何调参（改 `RERANK_K`、改切块、换 embedding）都是在脏数据上试，结论全是假的。

**把结论写进 `Day2任务.md` 2.5 的空白模板**（已填，`Day2任务.md` 里同步）：

